# ♻️ Système Intelligent de Classification des Déchets

##  À propos du projet
Ce projet de vision par ordinateur a pour objectif de classifier automatiquement différents types de déchets à partir d'une image fournie par l'utilisateur. En s'appuyant sur des algorithmes d'apprentissage profond, le système analyse les caractéristiques visuelles de l'image insérée pour prédire sa catégorie exacte et faciliter le tri sélectif.

##  Fonctionnalités principales
* Importation d'images : Interface permettant d'insérer ou de télécharger facilement un fichier image.
* Détection et Classification IA : Analyse automatisée de l'image par le modèle pour identifier la nature du déchet.
* Prédictions fiables : Optimisation du modèle pour garantir une reconnaissance précise des catégories.

##  Technologies et Outils
* Langage : Python
* Machine Learning / Deep Learning : PyTorch
* Environnement : Jupyter / VS Code / Git & GitHub

##  Structure du projet
- `model/` : Contient le modèle entraîné et les scripts associés.
- `data/` : Dossier pour la préparation et le prétraitement des images.
- `README.md` : Documentation du projet.
